## ⚙️ 5. Technische Hermes-Architektur: Wie Badges generiert werden

### Was Hermes für die Badge-Produktion im Backend benötigt:

1. **INPUT PAYLOAD (Trigger durch User-Aktion)**:
   - User ID & Username
   - Milestone ID (z.B. `badge_wave_master`)
   - GPS-Koordinaten (Latitude / Longitude des Freischaltens)
   - Kategorie & Rarity Tier (Bronze, Silber, Gold, Platin)

2. **VEKTOR-KOMPOSITIONS-PIPELINE (Hermes SVG Engine)**:
   - Grundraster: Kreis 500x500 mit 2px Doppelkontur
   - Metallic Gradient Injection (Gold / Cyan / Emerald)
   - Zentriertes Hobby-Vektormuster
   - Text-on-Path: Username + GPS-Koordinaten + Brand

3. **MULTI-FORMAT EXPORT & POD DISPATCH**:
   - Web SVG (für DOM-Rendering & interaktive Karten-Pins)
   - 300 DPI CMYK PDF (an Printful / Contrado POD API)
   - Transparente PNG Maske (für digitalen Reisepass)
   - Eintragen in Supabase DB: `user_badges` Tabelle
