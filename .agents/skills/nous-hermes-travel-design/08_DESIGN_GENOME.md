# NOUS HERMES — DESIGN GENOME & UNIQUENESS ENGINE

## Mission
Prevent repetitive AI design output.

Every finished design receives a Design Genome.

## Genome fields
- emotional core
- palette family
- tonal structure
- contrast strategy
- typography family
- type hierarchy
- composition
- focal geometry
- gaze direction
- viewpoint
- pattern system
- travel vocabulary
- image treatment
- material treatment
- badge integration
- Easter-egg method
- garment placement
- production method

## Similarity scoring
Compare a new design against previous designs.

Score each dimension 0–5 for similarity.

0 = unrelated
5 = essentially repeated

If multiple major dimensions score 4–5, redesign.

## Hard anti-repetition rule
Changing only:
- color
- destination
- wording
- icon
is NOT a new design.

A true new design changes the underlying visual grammar.

## Mutation strategies
Change one or more major dimensions:
- central → asymmetric
- illustration → photography
- flat → layered
- geometric → organic
- editorial → technical
- monochrome → accent system
- aerial → eye-level
- dense → minimal
- typography-led → image-led
- pattern-led → silhouette-led

## Brand consistency
Keep the brand's emotional DNA consistent while allowing product-level visual DNA to vary.

## Archive
Maintain a machine-readable history of previous genomes and reject high-overlap concepts before refinement.
