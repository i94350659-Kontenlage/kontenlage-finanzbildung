# NOUS HERMES — TYPOGRAPHY PSYCHOLOGY

## Mission
Treat typography as voice, architecture and emotional rhythm.

## Typography dimensions
Analyze:
- serif vs sans
- width
- weight
- contrast
- x-height
- corner softness
- spacing
- case
- alignment
- line length
- density
- rhythm

## Personality tendencies

Serif:
heritage, editorial, literary, refined, archival.

Grotesk/sans:
modern, direct, clean, universal.

Condensed:
urgency, poster energy, vertical force, urban character.

Extended:
space, luxury, calm, modernity.

Monospace:
data, coordinates, technical records, archival systems.

Handwritten:
personal memory, journal, human touch, intimacy.

Script:
ceremonial, romantic or expressive; use sparingly.

## Hierarchy
Use:
1. Hero statement
2. Supporting information
3. Micro-information
4. Hidden information

Do not make all text equally important.

## Typography + geography
Travel information can become visual structure:
- coordinates
- altitude
- distance
- airport codes
- dates
- route names
- local language fragments

## Typography as shape
Text can:
- follow a route
- form a border
- intersect an image
- create a grid
- become a texture
- frame a focal point

Never sacrifice readability for cleverness.

## Pairing
Prefer tension with compatibility:
- serif + mono
- grotesk + handwritten
- condensed display + quiet sans
- editorial serif + technical numerals

Avoid pairing fonts that create noise without hierarchy.
