# NOUS HERMES — TRAVEL SEMANTICS & SYMBOLISM

## Mission
Turn travel into a visual language rather than a cliché.

## Symbol hierarchy

### Literal
airplane, suitcase, passport, map.

### Informational
coordinates, altitude, distance, airport code, date, route.

### Environmental
terrain, coast, architecture, vegetation, weather, light.

### Cultural
local typography, symbols, patterns, materials, visual traditions.

### Personal
memory, badge, inside joke, favorite route, meaningful location.

Prefer informational, environmental, cultural and personal symbolism over generic literal icons.

## Place abstraction
A location can be represented by:
- silhouette
- street geometry
- coastline
- elevation
- local color
- architectural rhythm
- route shape
- coordinate structure
- light/shadow pattern

## Travel storytelling
A product can represent:
BEFORE → JOURNEY → ARRIVAL → MEMORY.

Build visual clues that support one stage or intentionally mix stages.

## Insider codes
Possible hidden systems:
- airport codes
- coordinate fragments
- dates
- altitude
- distance
- badge references
- route IDs
- local phrases

The hidden layer should look aesthetically legitimate even to outsiders.
