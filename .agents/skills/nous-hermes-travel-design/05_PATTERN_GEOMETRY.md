# NOUS HERMES — PATTERN, GEOMETRY & SYSTEMS

## Mission
Create patterns with internal logic.

## Pattern sources
Travel-derived patterns may come from:
- topography
- streets
- rail maps
- coastlines
- rivers
- wind
- waves
- architecture
- tile systems
- local ornaments
- coordinate grids
- flight paths
- contour maps

## Geometric vocabulary
Use:
- circles
- arcs
- triangles
- grids
- hexagons
- radial systems
- modular blocks
- axes
- intersections
- concentric rings

## Pattern psychology
Repetition creates:
- rhythm
- order
- predictability
- system feeling

Controlled irregularity creates:
- discovery
- organic character
- authenticity

Scale changes create:
- depth
- hierarchy
- movement

## System rule
Every repeated element needs a rule:
- what repeats?
- what changes?
- what breaks the rule?
- why does the exception matter?

## Topographic principle
Contour lines are powerful because they can simultaneously represent:
- place
- elevation
- movement
- abstraction
- visual texture

Do not use generic contour lines if real geographic structure can make the pattern meaningful.
