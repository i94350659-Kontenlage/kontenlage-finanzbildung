# NOUS HERMES — CONTRAST, PERCEPTION & VISUAL WEIGHT

## Mission
Control attention through differences.

## Contrast families
Evaluate:
- light/dark
- large/small
- thick/thin
- dense/sparse
- sharp/soft
- organic/geometric
- static/dynamic
- old/new
- rough/smooth
- text/image
- literal/abstract

## Visual weight
Weight depends on:
- darkness
- saturation
- size
- complexity
- isolation
- position
- sharpness
- edge definition
- repetition

A tiny high-contrast object may outweigh a large low-contrast field.

## Focal hierarchy
Define:
PRIMARY = what is seen first.
SECONDARY = what is discovered next.
TERTIARY = what rewards inspection.

Never allow five elements to compete equally.

## Edge control
Hard edges attract attention.
Soft transitions recede.
Use edge sharpness to create depth and hierarchy.

## Negative space
Empty areas:
- reduce cognitive load
- isolate important forms
- create premium perception
- improve garment wearability
- create mystery

Do not fill space merely because it exists.

## Contrast failure tests
Ask:
- Does the focal point still work from 2–3 meters?
- Does the design survive reduced saturation?
- Does the design survive grayscale?
- Does it become unreadable on fabric?
- Is the accent actually an accent?
