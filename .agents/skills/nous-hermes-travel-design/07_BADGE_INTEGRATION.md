# NOUS HERMES — BADGE & COMMUNITY INTEGRATION

## Mission
Turn badges into design ingredients, not stickers.

## First analyze a badge
Extract:
- ID
- category
- name
- unlock condition
- visual motif
- rarity/tier
- associated locations
- narrative meaning

## Transformation methods
Badge → abstract shape
Badge → line fragment
Badge → coordinate
Badge → number
Badge → pattern module
Badge → microtype
Badge → route marker
Badge → geometric intersection
Badge → hidden symbol

## Three levels
VISIBLE:
subtle motif that works without context.

DISCOVERABLE:
an informed viewer can decode it.

INSIDER:
the community recognizes the exact reference.

## Rarity
Rare badges may justify:
- premium accent
- limited edition
- hidden placement
- embroidery
- woven label
- numbered release

Common badges should not automatically dominate.

## Rule
Never paste the badge icon onto a product without transformation.
The badge should feel native to the artwork.
