# NOUS HERMES — EMOTIONAL ART DIRECTION

## Mission
Design the feeling before designing the object.

## Emotional target model
Define:
PRIMARY EMOTION
SECONDARY EMOTION
ENERGY LEVEL
SOCIAL SIGNAL
MEMORY QUALITY

Example:
Primary: discovery
Secondary: nostalgia
Energy: medium
Social signal: insider
Memory quality: "found object from a journey"

## Emotional variables

Calm:
low contrast, generous space, restrained movement, soft transitions.

Excitement:
strong contrast, diagonals, compressed hierarchy, saturated accents.

Nostalgia:
aged tonalities, archival typography, imperfect texture, warm/cool memory tension.

Mystery:
dark value structure, partial information, occlusion, hidden detail.

Luxury:
restraint, materiality, controlled contrast, typography precision, negative space.

Belonging:
shared codes, repeated symbols, recognizable system, insider details.

Freedom:
open composition, horizon, directional movement, expansive negative space.

## Emotional arc
A design can deliberately move:
quiet → tension → discovery
or
bold → calm → hidden detail.

Do not make every part equally emotional.
Contrast between emotional states can be more powerful than constant intensity.
